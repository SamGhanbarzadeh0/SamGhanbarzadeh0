# Sam Ghanbarzadeh

**M.Sc. in Biomedical Engineering (Bioelectric)**  
Iran University of Science and Technology (IUST)

My work combines neural electrophysiology, computational neuroscience, and signal processing. I use Python and MATLAB to examine neural recordings and behavioral data, with an emphasis on careful measurement and reproducible analysis. I also serve as a teaching assistant in Digital Signal Processing and Pattern Recognition at IUST.

### Current research

**IBL Brain-Wide Map — Neural Electrophysiology and Behavioral Data Analysis**

My graduate research uses publicly available recordings from the International Brain Laboratory, including pre-sorted spike trains, local field potentials (LFP), and associated behavioral measurements. I work on data preparation, quality assessment, and quantitative analysis of these recordings.

### Previous academic projects

**Computational neuroscience**
- **[Extracellular spike sorting (2019)](https://github.com/SamGhanbarzadeh0/Extracellular-Spike-Sorting):** Comparative evaluation of detection, feature extraction, and clustering methods using reference-annotated simulated recordings. The published repository includes the 2026 Python validation and documentation.
- **Neural response encoding and decoding:** Academic work examining quantitative descriptions of neural responses and their relationship to experimental variables.

**Brain–computer interfaces**
- **[Motor-imagery EEG classification (2018)](https://github.com/SamGhanbarzadeh0/BCI-Motor-Imagery):** Initially developed in MATLAB. A subsequent Python CSP benchmark is undergoing technical review before public release.

The neural response encoding/decoding project is not yet hosted as a standalone public repository. The motor-imagery EEG repository is an empty placeholder; its code, notebooks, and results have not yet been published.
